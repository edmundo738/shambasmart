# shambasmart
Um app mobile + web AgroTech, chamado CHAMBA / ShambaSmart, que conecta camponeses, compradores, transportadores, estudantes e investidores, gerando renda, impacto social, sustentabilidade e engajamento real.

## Prompt compacto e funcional — Shambaverse Agrotech Angola

Use o prompt abaixo para gerar um protótipo completo, realista e funcional da plataforma Shambaverse.

> You are a senior full-stack app developer and product designer. Your task is to **create a complete, fully functional mobile app** called *Shambaverse*, an Agrotech platform for Angola. The app must **solve real problems for small/medium farmers and producers**. Focus on **practical utility first, engagement second**. Provide **screens, navigation flow, backend structure, database, and code scaffolding**.
>
> **Requirements:**
>
> 1. **Users:** Farmers, producers, buyers, transporters, visitors.
>
> 2. **Problems to solve:**
>
>    * Lack of market visibility → solution: marketplace with product listings and prices.
>    * Transport/logistics difficulty → solution: transport booking and tracking.
>    * Agricultural info gap → solution: alerts on climate, pests, best planting periods.
>    * Production management → solution: dashboard for cost/revenue/crop planning.
>
> 3. **Core Features:**
>
>    * User authentication (login/signup) and profile.
>    * Marketplace: list products, see regional prices, connect buyers/sellers.
>    * Transport scheduling: book, track, and confirm delivery.
>    * Alerts: push notifications for climate, pests, planting tips.
>    * Dashboard: simple crop, cost, revenue management.
>    * Optional: social layer for tips and success stories after main features.
>
> 4. **UI/UX:**
>
>    * Modern, minimalist, intuitive, mobile-first.
>    * Color palette: green, earth tones, yellow; convey growth, trust, agriculture.
>    * Offline/low-data mode for rural areas.
>    * Icons clearly indicate marketplace, transport, alerts, dashboard.
>
> 5. **Output Expected:**
>
>    * **Screen flows**: Home, Marketplace, Transport, Alerts, Dashboard, Profile, Chat.
>    * **Components**: Buttons, lists, forms, alerts, cards, notifications.
>    * **Backend & Database**: Lightweight, low-bandwidth, cloud-ready. Suggest Firebase or local SQL-based solution. Include tables for users, products, orders, transport, alerts.
>    * **Code scaffolding**: React Native (iOS + Android) with sample functions for each feature.
>    * **Logo & Branding**: Simple, agrotech, trustworthy, modern. Suggest colors, icons, typography.
>    * **All interactions functional**: Each button, click, or navigation leads to a working response.
>
> 6. **Instructions:**
>
>    * Generate a **full prototype-ready app** with **screens, flows, backend and sample code**.
>    * Include explanations of how each feature solves a **real problem for Angolan farmers**.
>    * Use **realistic Angolan examples** for products, towns, prices, transport.
>    * Ensure **all clickable items are functional** in the prototype.
>    * The app should be **engaging, but fully practical**.
>
> 7. **Account & Ownership:**

>
> **Goal:** Produce a **ready-to-build full app**, not just mockups. Every feature must have **functional interaction and backend logic**, suitable for prototyping or production.
